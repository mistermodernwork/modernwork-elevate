# ModernWork Elevate 1.4.2

Cleaner logs: no more sign-in names from Microsoft's error messages.

## Improved

- **No sign-in names in the log.** Error messages from Microsoft Graph, Azure Resource Manager and
  the sign-in can name your account (for example "The client 'alice@contoso.com' does not have
  authorization …"). The app now masks those addresses before anything is written to the log file;
  error code, HTTP status and request id stay, so support can still follow up.
