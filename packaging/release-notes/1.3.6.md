# ModernWork Elevate 1.3.6

Sign-in windows only when you ask for them, a new icon, and Azure resource roles that come back
on their own.

## Fixed

- **No more sign-in windows out of nowhere.** The list refreshes in the background without ever
  opening a Windows sign-in window. When a tenant needs you to sign in again, its card says
  *Sign-in required* — click **Refresh** and one window per account opens.
- **One window, not several.** If you close a sign-in window, the app does not open the next one
  right away for the same click.
- **The sign-in window stays.** The panel no longer hides while a Windows sign-in window is open,
  and sign-in and MFA have five minutes instead of thirty seconds.
- **Works behind a proxy with tenant restrictions.** Where only the sign-in pages go through your
  proxy, the app signs in to the proxy with your Windows logon, like Edge. If your organization's
  tenant restrictions block a tenant, the app says so and names the setting an admin changes.
- **Clearer Azure messages.** When Azure resource roles cannot be loaded, the note says why: Azure
  Resource Manager blocked by a proxy or firewall, a proxy that asks for sign-in, or a temporary
  problem that heals itself.

## Improved

- **New icon.** A blue tile with an upward arrow in the taskbar, the Start menu and Apps &
  features. The coloured dot still shows your status at a glance.
- **Reloads when the network comes back** — after logon, wake-up or a VPN connect — and retries
  every 20 seconds while a tenant shows a load error.
- **Network check tells proxy and direct apart.** A proxy that refuses the request (HTTP 407)
  shows as a failure, and each host shows whether it went through the proxy or direct.
