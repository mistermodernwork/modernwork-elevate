# ModernWork Elevate 1.3.1

A new icon, and Azure resource roles that come back on their own.

## Improved

- **New icon.** A blue tile with an upward arrow — elevate — in the taskbar, the Start menu and
  Apps & features. The coloured dot still tells you your status at a glance.
- **Reloads when the network comes back.** After logon, wake-up or a VPN connect the list reloads
  by itself within seconds, instead of keeping an old error until the next minute.
- **Retries sooner after an error.** While a tenant shows a load error, the list tries again every
  20 seconds. A short hiccup of the network or the Windows sign-in no longer hides your Azure
  resource roles for an hour.
- **Refresh means refresh.** The refresh button and the tray menu ask Azure again, even for a
  tenant that failed before.

## Fixed

- **Works behind a proxy with tenant restrictions.** Where only the sign-in pages go through your
  proxy, the app now signs in to the proxy with your Windows logon, like Edge, instead of being
  turned away. If your organization's tenant restrictions block a tenant, the app says so and
  names the setting an admin changes.
- **Network check tells proxy and direct apart.** A proxy that refuses the request (HTTP 407)
  shows as a failure, and each host shows whether it went through the proxy or direct.

- **Clearer Azure messages.** When Azure resource roles cannot be loaded, the yellow note now says
  why: Azure Resource Manager blocked by a proxy or firewall, a proxy that asks for sign-in, or a
  temporary sign-in problem that heals itself — instead of "Couldn't load eligibilities".
